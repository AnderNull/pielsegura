# PielSegura

App web de apoyo para Enfermería que valora el riesgo de lesiones por presión con la escala de Braden.

## Funciones

- Valoración guiada de las 6 subescalas de Braden.
- Puntaje automático y semáforo de 5 niveles de riesgo.
- Plan de cuidados preventivo según el riesgo y los factores del paciente.
- Nota de enfermería lista para copiar.
- Mensaje para la familia en lenguaje sencillo.

## Uso responsable

Herramienta de apoyo académico: no reemplaza el criterio profesional. Use solo datos ficticios. La app no guarda información (Ley 1581 de 2012).
